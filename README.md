Household Water Usage and Billing System

📌 Project Description

This project is a simple Java-based Household Water Usage and Billing System developed to demonstrate basic Java programming concepts.

The project includes programs for recording household water usage, calculating total water consumption, and determining the water bill based on consumption.

🎯 Objectives

To understand basic Java programming concepts.

To work with variables and different data types.

To take input using the Scanner class.

To use conditional statements.

To create and use methods.

To perform calculations related to water consumption and billing.

📂 Project Files

1. HouseholdWaterUsage.java

This program stores and displays household water usage details such as:

Number of family members

Water consumed

House number

Water usage status

The program demonstrates the use of different Java data types such as int, double, and char.

2. WaterConsumption.java

This program accepts morning and evening water usage from the user and calculates the total consumption using a method.

Formula:

Total Water Consumption = Morning Usage + Evening Usage

3. WaterBill.java

This program accepts water consumption in litres and calculates the water bill using an if-else condition.

Consumption up to 500 litres → Rs.100

Consumption above 500 litres → Rs.200

🛠️ Technologies Used

Programming Language: Java

Input: Scanner

Concepts: Variables, Data Types, Operators, Conditional Statements, Methods

▶️ How to Run

Install Java JDK on your computer.

Download or clone this repository.

Open the project in any Java IDE such as IntelliJ IDEA, Eclipse, or VS Code.

Compile the required .java file.

Run the program.

Example:

javac WaterConsumption.java
java WaterConsumption
